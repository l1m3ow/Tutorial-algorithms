## **Что такое O-большое?**

**O-большое** — это математическая нотация, которая описывает скорость роста времени выполнения алгоритма в зависимости от объема входных данных. Она позволяет сравнить эффективность алгоритмов. Важно понимать, что O-большое рассматривает худший сценарий (верхнюю границу) количества операций.

**Типичные примеры сложности:**

* O($log_2n$) — логарифмическая сложность (очень быстрый алгоритм).

* O($n$) — линейная сложность (быстрый алгоритм).

* O($n * log_2n$) — линейно-логарифмическая сложность (средняя эффективность).

* O($n^2$) — квадратичная сложность (медленный алгоритм).

* O($n!$) — факториальная сложность (очень медленный алгоритм).

## **В чём заключается стратегия "разделяй и властвуй"?**

**Стратегия "разделяй и властвуй" (Divide and Conquer)** — это подход к решению сложных задач путём:

1. Разделения исходной задачи на несколько меньших и независимых подзадач того же типа.

2. Рекурсивного решения каждой подзадачи.

3. Комбинирования результатов подзадач в общее решение исходной задачи.

**Примеры : Бинарный поиск, Быстрая сортировка, НОД**

## **Что такое рекурсивный стек?**

**Стек (stack)** — структура данных, работающая по принципу LIFO (Last In, First Out).

**Рекурсивный вызов** — когда функция вызывает саму себя.

При каждом рекурсивном вызове в стеке сохраняются:

* Локальные переменные функции.

* Адрес возврата (куда вернуться после выполнения).

* Параметры функции.

**Глубина рекурсии** — количество вызовов, которое соответствует текущей высоте стека.

Если рекурсия слишком глубокая, возникает переполнение стека (stack overflow).

**Пример:**

```
factorial(3)
  -> factorial(2)
    -> factorial(1)
    возврат 1
  возврат 2 * 1 = 2
возврат 3 * 2 = 6
```
